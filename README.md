# لوحة تحكم AutoDev Agency

لوحة تحكم كاملة لإدارة موقع الوكالة — **غير مربوطة بـ Backend حالياً** لكنها مصممة لتكون جاهزة 100% للربط لاحقاً.

## التشغيل

افتح الملف:

```
autodev/dashboard/index.html
```

في المتصفح مباشرة، أو عبر Live Server.

## الأقسام المتوفرة

| القسم | الوظيفة |
|--------|---------|
| **نظرة عامة** | إحصائيات حية، رسم بياني لتوزيع الطلبات، أحدث الطلبات والرسائل |
| **الطلبات** | استقبال وإدارة طلبات "ابدأ مشروعك" (جديد / تواصل / عرض / اتفاق / خسارة) |
| **العملاء** | إضافة وتعديل العملاء + الإيرادات والمشاريع المرتبطة |
| **المشاريع** | إدارة بورتفوليو الموقع (عناوين متعددة اللغات، فئات، تقنيات، ظهور) |
| **الشركاء** | إدارة الشركاء (تقني / تسويقي / وكالة) |
| **عقود الشراكة** | عقود مع تواريخ وقيم وشروط |
| **الإعلانات** | حملات إعلانية + ميزانيات + مصروف + ظهور + نقرات + تحويلات |
| **الرسائل** | رسائل نموذج التواصل |
| **الخدمات** | خدمات الموقع الظاهرة للزوار |
| **الإعدادات** | بيانات الشركة + تصدير JSON + إعادة تعيين البيانات |

## تخزين البيانات حالياً

- كل شيء يُحفظ في **localStorage** للمتصفح.
- بيانات تجريبية جاهزة تظهر فوراً عند أول فتح.
- يمكنك تصدير نسخة احتياطية JSON من صفحة الإعدادات.

## الربط مع Backend لاحقاً (مهم)

الواجهة **لا تتصل مباشرة** بـ localStorage. كل شيء يمر عبر طبقة API:

```
dashboard/js/api.js
```

عند الربط مع Supabase أو أي REST API:

1. افتح `js/api.js`
2. استبدل فقط الدوال:
   - `list(collection)`
   - `get(collection, id)`
   - `create(collection, payload)`
   - `update(collection, id, payload)`
   - `remove(collection, id)`
   - `getSettings()` / `updateSettings()`
3. **لا تلمس** `app.js` أو `index.html` — الواجهة ستعمل مباشرة.

هياكل البيانات متوافقة مع جداول متوقعة مثل:
`requests`, `clients`, `projects`, `partners`, `contracts`, `ads`, `messages`, `services`, `categories`, `settings`
