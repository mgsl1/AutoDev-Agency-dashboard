# AutoDev Agency — صفحة البورتفوليو

تفتح من الزر **"مشاريعنا"** في الصفحة الرئيسية (`../index.html`).

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | بنية الصفحة (hero، مشاريع، من نحن، خدمات، طريقة العمل، تواصل، شات AI) |
| `style.css` | التصميم بألوان AutoDev (سماوي/أزرق على خلفية داكنة) + وضع فاتح |
| `script.js` | الترجمة (عربي/فرنسي/إنجليزي)، الثيم، البريلودر، ومساعد الشات الذكي |
| `backend.js` | العرض الديناميكي + نموذج التواصل + الإعجابات والمشاركة |
| `data.js` | **محتوى المشاريع** — عدّل هنا لإضافة أو حذف مشروع |
| `config.js` | إعدادات الاتصال (Supabase اختياري) + رقم الواتساب والبريد |

## إضافة مشروع
افتح `data.js` وانسخ أي عنصر داخل `AUTODEV_PROJECTS`، ثم غيّر:
`id`, `title`, `short_description`, `description`, `features`, `cover_image_url`,
`project_category_links` (حسب `AUTODEV_CATEGORIES`) و`project_technologies`.
ضع الصور داخل مجلد `assets/`.

## الشات الذكي
يعمل بدون أي مفتاح API: قاعدة معرفة محلية بثلاث لغات داخل `script.js`
(ابحث عن `Local fallback knowledge base`). عدّل الإجابات أو أضف نوايا جديدة هناك.

## لوحة تحكم (اختياري)
إذا أردت التحكم بالمحتوى من قاعدة بيانات، ضع رابط ومفتاح Supabase العامّين في
`config.js` — عندها يتجاوز المحتوى القادم من قاعدة البيانات محتوى `data.js` تلقائياً.
